# Héloïse Lloris Champagne

Static single-page site for Héloïse Lloris, the first Champagne in the world encased and finished in 24K gold.

* Live: https://tarne75.github.io/heloiselloris/ (age-gated version: `/index-age-check.html`)
* How it's built and how to edit it: [CLAUDE.md](CLAUDE.md)
* Palette, typography and style rules: [BRAND.md](BRAND.md)

Zero dependencies: hand-written HTML, CSS and vanilla JS, self-hosted fonts and WebP images.
